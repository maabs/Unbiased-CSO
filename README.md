This repository contains two numerical examples of the unbiased Conditional Stochastic Optimization (CSO), in the first one we have the methodology applied to a hidden markov model with gaussian hidden model and a mixture of guassian and Student's-t obsevation model. 
The second project was build upon the project "scalable inference for a full multivariate stochastic volatility model", we use the developed methodology and apply the unbiased algorithm to it. 

# Unbiased Conditional Stochastic Optimization (CSO)

## Overview

This method combines the Stochastic Approximations (SA) and unbiased methods to tackle the problem of CSO. 

## Key Features

- Unbiased gradient estimation

- Markovian stochastic approximation

- Applications to MSV and state-space models
